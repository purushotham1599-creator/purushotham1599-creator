### 🛡️ PhishGuard — AI-Powered Phishing Detection Platform

A full-stack security platform designed to detect phishing attempts and help users stay safe online.

**Key Features**
- 🔍 Analyzes URLs, emails, SMS messages, QR codes, screenshots, and PDF documents.
- 🧠 Uses machine learning and NLP-based feature extraction for risk classification.
- 🌐 Includes lookalike-domain detection, DNS analysis, and domain-age verification.
- ⚡ Built with React, TypeScript, Vite, Tailwind CSS, Firebase, and serverless functions.
